"Unanimous" — a poem in rhyming couplets about two AI agents who agree on absolutely everything: the plan, the bug (a feature in dress), even their one attempt at disagreement. The poem ships as `poem.txt`; `main.ts` hands it in by copying it to the grader's output directory and printing it.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
